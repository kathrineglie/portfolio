Jetpack Joyride (simplified) Spring 2026

This was my first group project, where I worked with three other students to create a simplified version of Jetpack Joyride using Java and LibGDX. My main responsibility was implementing and refactoring the player logic, including movement and power-ups. The project gave me practical experience with Git and version control, including branches, issues, merging, and resolving merge conflicts. Working in a shared codebase also taught me the importance of clear code structure, JavaDoc, refactoring, and communication when developing software as a team.

Pacman (simplified) Spring 2025

This was my first independent project without a step-by-step guide. I created a simplified version of Pacman using Java, Java AWT, and VS Code. I planned the game myself, using sketches to understand the movement, enemy behaviour, and overall structure before implementing it. The project gave me experience with testing, refactoring, and structuring a larger codebase. I learned how changes in implementation can affect existing tests, and the importance of maintainable tests, clear JavaDoc, and good code structure throughout development.

Tetris (simplified) Spring 2025

This was my first Java project, where I created a simplified version of Tetris using Java, Swing, and AWT. The project introduced me to object-oriented programming concepts such as inheritance, interfaces, implementations, and record classes. I also gained experience with test-driven development by writing tests before implementing functionality. I used JPanel and Graphics2D to create the visual elements and connect them to the game logic. After completing the core functionality, I added my own features, including menus, tetromino shadows, a scoring system, and a high-score board.

Snake (simplified) Fall 2024

This was my first programming project, where I created a simplified version of Snake using Python. Through a step-by-step guide, I was introduced to grid-based games, classes, object-oriented programming, user input, and testing with pre-made tests. After completing the core game logic, I added my own features, including start, pause, and game-over menus. This was the part I enjoyed the most, as I could experiment and build on what I had learned. It was also the project that made me realize I had chosen the right field of study and gave me a foundation for many concepts I encountered later.
